### 수집 주기
- **현재**: 주 1회 (매주 월요일 자정)
- **변경 예정**: 매일 (매일 자정)

### 수집 데이터량
- **차트 데이터**: 약 200-300개 웹툰/수집 (요일별로 나뉨)
- **상세 정보**: 약 200-300개 웹툰/수집
- **총 레코드/수집**: 약 400-600개

## GCP Always Free 한도

### 1. Cloud Functions

**무료 한도**:
- 요청 수: **200만 회/월**
- 컴퓨팅 시간: **400,000 GB-초/월**
- 네트워크 송신: **5GB/월**

**현재 사용량 (주 1회 기준)**:
- 월 실행 횟수: **4-5회**
- 예상 요청 수: **4-5회**
- 예상 컴퓨팅 시간: **약 20-30 GB-초/월** (함수당 5-6GB-초 가정)
- 예상 네트워크 송신: **약 0.1GB/월**

**매일 수집 시 (변경 후)**:
- 월 실행 횟수: **30-31회**
- 예상 요청 수: **30-31회**
- 예상 컴퓨팅 시간: **약 150-200 GB-초/월**
- 예상 네트워크 송신: **약 0.6-0.8GB/월**

**결론**: ✅ **Always Free 범위 내** (여유 있음)

---

### 2. Cloud Scheduler

**무료 한도**:
- 작업 수: **3개 작업/월** (무료)
- 작업 실행: **무제한** (무료)

**현재 사용량**:
- 작업 수: **1개** (naver-webtoon-weekly-collection 또는 kakao-webtoon-weekly-collection)

**매일 수집 시**:
- 작업 수: **1개** (변경 없음)

**결론**: ✅ **Always Free 범위 내**

---

### 3. Cloud Storage (GCS)

**무료 한도**:
- 저장 용량: **5GB**
- Class A 작업 (읽기/쓰기): **5,000회/월**
- Class B 작업 (목록): **50,000회/월**
- 네트워크 송신: **1GB/월**

**현재 사용량 (주 1회 기준)**:
- 저장 용량: **약 0.5-1GB** (HTML 원본 파일)
- Class A 작업: **약 8-10회/월** (파일 업로드)
- Class B 작업: **약 10-20회/월** (목록 조회)

**매일 수집 시 (변경 후)**:
- 저장 용량: **약 15-20GB/월** (30일 × 0.5-0.7GB/일)
  - ⚠️ **5GB 한도 초과 가능성**
- Class A 작업: **약 60-90회/월** (파일 업로드)
- Class B 작업: **약 60-90회/월** (목록 조회)

**결론**: ⚠️ **저장 용량 한도 초과 가능** (5GB 한도)

**해결 방안**:
1. **오래된 데이터 삭제**: 3개월 이상 된 HTML 파일 자동 삭제
2. **압축 저장**: HTML 파일 압축하여 저장
3. **선택적 저장**: 에러 발생 시에만 HTML 저장

---

### 4. BigQuery

**무료 한도 (2025-2026 최신 정책)**:
- 저장 용량: **10 GiB/월** (첫 10GB 무료)
- 쿼리 처리량: **1 TiB/월** (첫 1TB 무료)
- 스트리밍 삽입: 
  - Legacy Streaming: **$0.01/200MB** (유료)
  - Storage Write API: **첫 2TB 무료**, 이후 **$0.025/GB**
- 액티브 스토리지 (최근 90일 수정): **$0.02/GB/월**
- 롱텀 스토리지 (90일 이상 미수정): **$0.01/GB/월**

**현재 사용량 (주 1회 기준)**:
- 저장 용량: **약 391KB** (5,358개 레코드, 7일 수집)
- 쿼리 처리량: **약 0.01-0.05GB/월** (MERGE 쿼리)
- 예상 월간 증가: **약 0.05-0.1GB/월** (주 1회 기준)

**매일 수집 시 (변경 후)**:
- 저장 용량: **약 1.5-3GB/월** (30일 × 0.05-0.1GB/일)
  - ⚠️ **10GB 한도 초과 가능성** (6-7개월 후)
- 쿼리 처리량: **약 0.3-1.5GB/월** (MERGE 쿼리)
- 스트리밍 삽입: 배치 업로드 사용 시 무료 (Storage Write API 2TB 무료 범위 내)

**결론**: ⚠️ **저장 용량 한도 초과 가능** (6-7개월 후)

**해결 방안**:
1. **파티션 기반 삭제**: 오래된 파티션 자동 삭제 (예: 1년 이상 된 데이터)
2. **데이터 압축**: BigQuery는 자동 압축되지만, 불필요한 컬럼 제거
3. **선택적 저장**: 중복 데이터 최소화

**시나리오 2: 한도 초과 시 (최악의 경우)**

## 권장 사항

### 1. GCS 저장 용량 관리
```bash
# 3개월 이상 된 파일 자동 삭제
gsutil -m rm gs://bucket-name/raw/2024-*.html  # 예시
```

### 2. BigQuery 파티션 관리
```sql
-- 1년 이상 된 파티션 삭제
DELETE FROM `naver-webtoon-collector.naver_webtoon.fact_weekly_chart`
WHERE chart_date < DATE_SUB(CURRENT_DATE(), INTERVAL 1 YEAR);
```

### 3. 모니터링 설정
- GCS 저장 용량 알림 (4GB 초과 시)
- BigQuery 저장 용량 알림 (8GB 초과 시)
